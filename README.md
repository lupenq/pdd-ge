# PDD GE Learning App

Приложение на Swift для изучения билетов ПДД Грузии. Текущая версия содержит мок-данные и подготовлена к подключению реального API. Основная цель — режим обучения, в котором вопросы выпадут из выборки после 4 правильных ответов на них.

## Основные возможности
- 🎯 **Режим обучения**: случайная выдача вопросов, удаление из выборки после 4 правильных ответов на один и тот же вопрос.
- 📚 **Структура билетов**: модели `Ticket`, `Question`, `AnswerOption` и прогресс `TrainingProgress` позволяют легко перейти на реальные данные.
- 🌐 **Подготовка к API**: `APIClient` и `RemoteQuestionProvider` ожидают реальный эндпоинт; пока используется `MockQuestionProvider`.
- 📊 **Отслеживание прогресса**: число правильных/неправильных ответов, оставшихся и завершённых вопросов.
- 🖥️ **SwiftUI-интерфейс (iOS)**: экран `TrainingView` с кнопками ответов и индикаторами прогресса. В не-iOS средах доступен CLI-демо режим.

## Структура кода
- `Sources/pdd-ge/Models.swift` — модели данных билетов и прогресса.
- `Sources/pdd-ge/DataSources.swift` — протоколы и реализации для мок- и будущего удалённого API.
- `Sources/pdd-ge/TrainingSession.swift` — логика режима обучения и удаления вопросов после 4 правильных ответов.
- `Sources/pdd-ge/TrainingView.swift` — SwiftUI-экран и модель представления (компилируется только при наличии SwiftUI).
- `Sources/pdd-ge/pdd_ge.swift` — точка входа: SwiftUI App для iOS или CLI-демо для других платформ.

## Запуск CLI-демо
В среде без SwiftUI можно запустить демонстрацию:

```bash
swift run
```

Демо загрузит мок-билеты, случайным образом ответит на несколько вопросов и выведет статистику. Для iOS-проекта используйте `QuestionRepository` и `TrainingView` внутри собственного App-пакета.
